# Filtering Preferences

## High-Signal Criteria

- Changes a decision, workflow, system design, or evaluation method.
- Provides a mechanism, tradeoff, constraint, or failure mode.
- Is likely to be useful again.

## Downrank Criteria

- Hype without mechanism.
- Rankings without decision criteria.
- Benchmarks without methodology.
- News that is novel but not relevant.
