# Alignment Rubric

Use this rubric to decide whether AI-related material deserves the user's attention and long-term storage.

## Three-Tier Judgment

### Write Now

Use when the source is high quality and strongly aligned with the user's long-term interests.

Typical signs:

- changes product, system, workflow, evaluation, or market judgment
- explains a mechanism, tradeoff, constraint, or operating pattern
- provides first-hand builder, operator, researcher, or maintainer evidence
- connects to an existing theme or recurring decision area
- is likely to be useful again in future work

### Ask First

Use when the source is useful but uncertain.

Typical signs:

- relevant, but not clearly durable
- interesting object, but not enough evidence for a dossier
- source quality is mixed
- depends on whether the user wants to track the topic
- may be better as a short note than a full wiki page

### Skip

Use when the source is weak or poorly aligned.

Typical signs:

- mostly hype, ranking, or generic commentary
- only repeats known claims
- lacks mechanism, evidence, or tradeoff
- is interesting to the market but not to this user
- would create filing noise

## High-Signal Questions

Ask these before filing:

- Does this change what the user should build, buy, study, avoid, or monitor?
- Does it reveal a reusable pattern rather than a one-off update?
- Does it add evidence to an existing theme or dossier?
- Would future work benefit from being able to retrieve this?
- Can the source be summarized without copying large blocks of original text?

## Downranking Rules

Downrank by default:

- launch announcements with no mechanism
- benchmark posts without methodology
- tool lists with no decision criteria
- trend takes with no evidence
- content whose main value is novelty or social proof

## Filing Threshold

Do not file unless the retained summary can state at least one durable judgment:

- a mechanism
- a constraint
- a tradeoff
- a failure mode
- a reusable framework
- an entity worth tracking
- a change in priority
